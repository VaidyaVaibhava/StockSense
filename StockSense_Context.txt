1. PROJECT OVERVIEW
================================================================================
StockSense is an AI-Powered Autonomous Inventory Management System (IMS) built 
using the Mastra Framework. It is a full-stack Next.js 14 web application with 
TypeScript, Tailwind CSS, and a JSON-based data store (simulating SQLite for 
demo purposes on Windows).

Target: Indian warehouse/industrial context with INR (₹) currency, Indian 
locations, Indian supplier names, and Indian user personas.

================================================================================
2. TECH STACK
================================================================================
- Framework:    Next.js 14 (App Router)
- Language:     TypeScript
- Styling:      Tailwind CSS (Dark mode, Glassmorphism)
- Auth:         JWT + bcryptjs (password hashing, lockout, audit trail)
- Database:     JSON file store (data/stocksense_db.json)
- AI Agents:    6 simulated Mastra Framework agents
- Icons:        Lucide React

7. HOW TO RUN
===============================================================================
cd StockSense && npm install && npm run dev
Open: http://localhost:3000

To serve production build: npm run build && npm start
Docker build: docker build -t stocksense . && docker run -p 3000:3000 stocksense
To reset seed database: delete data/stocksense_db.json
